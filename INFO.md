# BookMory - Техническая информация

## Обзор проекта

BookMory - это полнофункциональный веб-сервис для планирования, учета и анализа времени, потраченного на чтение книг. Приложение позволяет пользователям управлять своей библиотекой, отслеживать прогресс чтения, вести статистику сессий и достигать целей по чтению.

---

## Технологический стек

### Backend

- **PHP 8.2** - основной язык программирования серверной части
  - Используется PHP-FPM для обработки PHP-запросов
  - Поддержка современных возможностей PHP 8.2

- **MySQL 8.0** - реляционная база данных
  - Хранение пользовательских данных, книг, сессий чтения и заметок
  - Использование InnoDB движка для транзакций и внешних ключей
  - Кодировка UTF8MB4 для поддержки всех символов Unicode

### Frontend

- **HTML5** - разметка страниц
- **CSS3** - стилизация с использованием:
  - CSS Variables (Custom Properties) для темизации
  - Flexbox и Grid Layout для адаптивной верстки
  - CSS Animations для интерактивности
  - Dark Mode тема по умолчанию

- **Vanilla JavaScript (ES6+)** - клиентская логика
  - Fetch API для AJAX-запросов
  - DOM манипуляции
  - Модальные окна и интерактивные элементы

### Веб-сервер и инфраструктура

- **Nginx** - веб-сервер и reverse proxy
  - Обработка статических файлов
  - Проксирование запросов к PHP-FPM
  - Кэширование статических ресурсов
  - Настройка MIME-типов

- **Docker & Docker Compose** - контейнеризация и оркестрация
  - Изоляция сервисов в отдельных контейнерах
  - Управление зависимостями между сервисами
  - Volumes для персистентности данных
  - Health checks для обеспечения готовности сервисов

### Мониторинг и метрики

- **Prometheus** - система сбора и хранения метрик
  - Сбор метрик из MySQL Exporter
  - Временные ряды для анализа производительности

- **Grafana** - платформа визуализации метрик
  - Дашборды для мониторинга базы данных
  - Графики и аналитика

- **MySQL Exporter** - экспортер метрик MySQL для Prometheus
  - Мониторинг состояния базы данных
  - Метрики производительности запросов

## Архитектурные паттерны

### 1. **Singleton Pattern (Одиночка)**
   - Класс `Database` реализует паттерн Singleton для управления единственным соединением с базой данных
   - Обеспечивает централизованное управление подключением и предотвращает множественные соединения

### 2. **Repository Pattern (подобие)**
   - Логика работы с базой данных инкапсулирована в отдельных файлах (books.php, reading_session.php и т.д.)
   - Каждый модуль отвечает за работу со своей сущностью

### 3. **MVC-подобная архитектура**
   - **Model**: Класс Database и SQL-запросы
   - **View**: PHP-шаблоны с HTML/CSS/JS (includes/header.php, includes/footer.php)
   - **Controller**: Логика в PHP-файлах (books.php, reading_session.php и т.д.)

### 4. **Session-based Authentication**
   - Аутентификация на основе PHP сессий
   - Middleware-функции (`requireLogin()`, `isLoggedIn()`) для защиты маршрутов
   - Централизованная проверка авторизации в `config/auth.php`

### 5. **Prepared Statements Pattern**
   - Использование PDO Prepared Statements для всех SQL-запросов
   - Защита от SQL-инъекций
   - Параметризованные запросы

### 6. **Separation of Concerns (Разделение ответственности)**
   - Конфигурация вынесена в отдельные файлы (`config/database.php`, `config/auth.php`)
   - Переиспользуемые компоненты (header, footer)
   - Логика отделена от представления

## Структура базы данных

### Таблицы

1. **users** - пользователи системы
   - Хранение учетных данных, профиля, статистики чтения
   - Поддержка streak (серий чтения)

2. **books** - книги пользователей
   - Информация о книгах (название, автор, страницы)
   - Статусы: To Read, Reading, Finished
   - Прогресс чтения (read_pages / total_pages)
   - Поддержка загрузки PDF-файлов

3. **reading_sessions** - сессии чтения
   - Отслеживание каждой сессии чтения
   - Дата, длительность, количество прочитанных страниц
   - Связь с книгой и пользователем

4. **memos** - заметки к книгам
   - Пользовательские заметки для каждой книги
   - Текстовые заметки с временными метками

### Связи

- **CASCADE DELETE**: При удалении пользователя автоматически удаляются все связанные данные
- **Foreign Keys**: Обеспечение целостности данных
- **Индексы**: Оптимизация запросов по user_id, status, session_date

## Безопасность

### Реализованные меры

1. **SQL Injection Protection**
   - Все запросы используют Prepared Statements
   - Параметризация всех пользовательских данных

2. **XSS Protection**
   - Использование `htmlspecialchars()` для экранирования вывода
   - Валидация и санитизация входных данных

3. **Session Security**
   - Проверка авторизации на защищенных страницах
   - Защита от несанкционированного доступа

4. **File Upload Security**
   - Валидация типов файлов (только PDF)
   - Уникальные имена файлов для предотвращения перезаписи
   - Изоляция загруженных файлов в отдельной директории

5. **Password Security**
   - Хеширование паролей с использованием `password_hash()` (bcrypt)
   - Проверка паролей через `password_verify()`

   - Реализованы на чистом JavaScript

   - Mobile-first подход

### 3. **Темная тема**
   - CSS Variables для легкой кастомизации цветов

   - Градиенты и тени для глубины

### 4. **Прогресс-бары**
   - Визуализация прогресса чтения книг
   - Динамическое вычисление процентов

### 5. **Статистика и аналитика**
   - Подсчет общей статистики по книгам
   - Анализ сессий чтения
   - Расчет средних показателей (скорость чтения, время на сессию)

## Интеграции

### Docker Compose Services

1. **db** (MySQL 8.0)
   - Основная база данных
   - Health checks для обеспечения готовности

2. **app** (PHP 8.2-FPM)
   - Обработка PHP-запросов
   - Установленные расширения: pdo_mysql, mbstring, gd, bcmath

3. **nginx** (Nginx Alpine)
   - Веб-сервер
   - Проксирование к PHP-FPM

4. **mysql-exporter**
   - Экспорт метрик MySQL

5. **prometheus**
   - Сбор и хранение метрик

6. **grafana**
   - Визуализация метрик

## Зависимости

### PHP Extensions
- `pdo_mysql` - работа с MySQL через PDO
- `mbstring` - работа с многобайтовыми строками
- `gd` - обработка изображений
- `bcmath` - математические операции с высокой точностью
- `exif` - работа с метаданными изображений
- `pcntl` - управление процессами

### Docker Images
- `php:8.2-fpm` - PHP с FastCGI Process Manager
- `mysql:8.0` - MySQL сервер
- `nginx:alpine` - легковесный Nginx
- `prom/prometheus:latest` - Prometheus
- `grafana/grafana:latest` - Grafana
- `quay.io/prometheus/mysqld-exporter` - MySQL Exporter
